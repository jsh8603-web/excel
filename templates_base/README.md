# templates_base/ — 채우기모드 베이스 템플릿 (선택)

빌더는 두 모드를 지원한다.

- **생성모드(create, 기본)**: `house_style`로 처음부터 작성. 차트·서식 전부 코드 생성. **권장**.
- **채우기모드(fill)**: 이 폴더의 베이스 `.xlsx`를 `openpyxl.load_workbook`으로 열어 **데이터 셀만**
  채우고 저장(값·서식·수식 보존). `render(..., mode="fill", base_path="templates_base/<x>.xlsx")`.

## ⚠ 라운드트립 한계 (중요)

openpyxl로 베이스를 열었다 저장하면 **차트·이미지·피벗·일부 고급서식이 빠질 수 있다.**
→ 베이스는 **표·서식 위주**로 만들고, **차트는 코드로 재생성**. 차트 많은 베이스는 생성모드 권장.

## 커밋 정책

- 현재 repo는 **private**(솔로 내부 사용) → 라이선스 보유/직접 제작 베이스 `.xlsx`를 **커밋 가능**.
  (Vertex42/CFI 등 재배포 금지 소스도 "본인 사용·비공개 저장"은 재배포 아님 — 단 ⚠ **public 재전환 시 반드시 제외**.)
- CFI/Macabacus/Vertex42 등의 포맷 "규약"은 `fpna/house_style.py`에 토큰화되어 있어, 베이스 파일 없이도
  맥킨지/회계법인 룩이 코드로 재현된다(라이선스 무관, 권장 기본값).

## 베이스 추가 방법

1. 폴리시된 `.xlsx`를 이 폴더에 둔다(데이터 셀은 비워두고 헤더/서식/수식만).
2. 해당 템플릿 빌더의 `mode="fill"` 분기에서 데이터 셀 좌표에 값을 기입(빌더별 구현 필요).
3. `tools/verify_xlsx.py`로 라운드트립 후 차트/서식 손실 여부 확인.
